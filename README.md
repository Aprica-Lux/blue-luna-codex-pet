# Blue Luna

Blue Luna is a Codex v2 animated pet: a magical fairy with blue horns and moonlight-colored hair.

## Features

- 9 standard Codex animation states: idle, directional movement, waving, jumping, failed, waiting, running, and review
- 16 clockwise look directions with cardinal and diagonal gaze poses
- 8×11 v2 sprite atlas using 192×208 cells
- 1536×2288 RGBA WebP spritesheet
- Transparent-background artwork prepared for Codex pet rendering

## Installation

Copy `pet.json` and `spritesheet.webp` into the Codex custom-pet directory:

```text
%USERPROFILE%\.codex\pets\luna-moonlight\
```

Restart Codex or reload the pet selector if Blue Luna does not appear immediately.

## Package

- `pet.json` — Codex custom pet v2 manifest
- `spritesheet.webp` — RGBA sprite atlas
- `assets/blue-luna-preview.gif` — GitHub preview animation

Codex uses `spritesheet.webp` for the actual pet animation.
